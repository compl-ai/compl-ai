# Provider logos

Logos are trademarks of their respective owners and are used only to identify each organization's models.

- Most files: [LobeHub Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg@1.102.0`, MIT).
- `xiaomi.svg`: [Simple Icons](https://simpleicons.org) (CC0). `xiaomi-color.svg` is the same mark filled with Simple Icons' brand hex `#FF6900`.

`<name>.svg` is single-colour; `<name>-color.svg` is the full-colour mark where one exists. The mapping from organization name to file lives in `public/data/providers.json`.
